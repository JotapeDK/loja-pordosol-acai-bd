# 🍨 Loja Açaí Pôr do Sol - Banco de Dados & Aplicação

Projeto desenvolvido para a **Feira Tecnológica da ETEC**, focado no gerenciamento, modelagem de banco de dados e regras de negócio para uma loja de açaí fictícia.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 🐍
- **Banco de Dados:** MySQL / SQL 🗄️
- **Controle de Versão:** Git & GitHub 🐙

---

## 📌 Funcionalidades e Estrutura

- Modelagem e estruturação do banco de dados relacional.
- Cadastro e gerenciamento de produtos, pedidos e clientes.
- Lógica de integração desenvolvida em Python (`main.py`).
